# Changelog

## 0.1.0

- Pruned the extension to two tools: `web_search` and `fetch_content`.
- Removed code search, result curation, commands, stored content retrieval, GitHub cloning, PDF extraction, YouTube/video handling, Gemini/browser-cookie integrations, and bundled skills.
- Simplified `fetch_content` to one HTTP(S) URL and ordinary HTML/text extraction.
